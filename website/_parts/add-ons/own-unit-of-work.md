- **Called while the handler list is built.** The library calls `ownUnitOfWorkOn<Ctx>()` once per run, when it builds the handler list, even for a Writer that a bypass then skips. An exception there is not logged, and the save fails.
- **Same parameter, your unit.** The Writer still registers through the `unitOfWork` its action receives. The library forwards the seven registration methods (`toInsert` and `toUpdate` for an SObject or a `DML.Record`, `toUpsert`, `toDelete` and `toPublish`) to the unit you returned. No other DML Lib method is reachable through it.
- **Commits at the Writer's turn.** The unit commits right after this Writer's Finalizer, or after its last record when it has no Finalizer, and only when at least one record qualified. Its rows are visible to SOQL before the next handler runs and before the shared unit commits, so a later handler's provider can query them.
- **Inside the error handling.** The commit runs inside the handler's try block. A failure is logged, then rethrown, or swallowed if the Writer implements ContinueOnError. When it is swallowed, statements of that commit that already succeeded stay.
- **Takes precedence over the private unit.** A Writer that implements both OwnUnitOfWork and ContinueOnError gets the unit it returns, not a private one.
- **Writers only.** On a Dispatcher the interface is ignored: the library never calls the method.
